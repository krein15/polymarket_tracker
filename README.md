# Polymarket Insider Activity Tracker

> **Статус: исследование завершено, проект закрыт 06.10.2026.**
> Репозиторий сохранён как отчёт о проделанной работе. Трекер
> работоспособен и может быть перезапущен, но развитие остановлено —
> потому что вопрос, ради которого он строился, получил ответ.

Система отслеживала сделки на [Polymarket](https://polymarket.com),
выделяла подозрительную активность и проверяла единственную гипотезу:
**можно ли заработать, повторяя за информированными трейдерами.**

Ответ: **нет.** Ниже — чем это измерено.

---

## Главный результат

### Информированные сделки существуют и опознаются

На 52 616 закрывшихся покупок, по цене самого трейдера:

| группа | сделок | цена входа | винрейт | перевес над безубытком |
|---|---:|---:|---:|---:|
| рынок пошёл следом | 8 938 | 60.3% | 80.5% | **+20.2 пп** |
| движения не было | 38 238 | 66.3% | 66.3% | −0.1 пп |
| рынок пошёл против | 5 440 | 62.0% | 36.5% | **−25.5 пп** |

Критерий «рынок пошёл следом» — за 20 минут после сделки другие
участники занесли деньги по цене выше. Классификация воспроизводится
внутри каждого коридора цен и на обеих половинах выборки по времени.

**И это не просто движение цены.** Если пересчитать перевес по цене
последователей, то есть по той, что движение уже вобрала:

```
его цена    0.603  →  перевес +20.2 пп
цена после  0.737  →  перевес  +6.9 пп   [ROI +9.1%, интервал +7.8…+10.4]
```

Движение объясняет две трети перевеса, но треть переживает его. Рынок
недореагировал. У этих людей действительно было знание.

### Воспользоваться им нельзя

| что мерили | результат |
|---|---|
| весь портфель по нашей цене входа, с лучшим фильтром | **−5.7%** [−9.2; −2.3], n=1 273 |
| лучшая ветка (ранние ончейн-сигналы) | −1.1% [−6.2; +4.1], n=547 |
| погоня по нашей цене | −1.2% [−12.5; +10.0], n=90 |

Причина одна и та же: перевес живёт в цене трейдера, а сигнал приходит
через 5–29 минут, когда цена уже ушла.

| ветка | запаздывание, медиана | переплата к его цене |
|---|---:|---:|
| ранний ончейн | 0.0 мин | +2.0% |
| белый список | 4.2 мин | +2.0% |
| score | 5.7 мин | +2.3% |
| погоня | 29.3 мин | **+59.4%** |

## Что ещё проверено и закрыто

### Детектор при равной цене не добавляет ничего

Если перевес объясняется тем, **по какой цене** мы покупаем, то детектор
— сложный способ купить фаворита. Сравнение внутри теневой выборки,
52 426 закрывшихся покупок, обе группы по цене трейдера:

| цена | сигнал был | сигнала не было | разница |
|---|---:|---:|---:|
| 0.30–0.50 | +0.42% | −0.56% | +0.97 пп |
| 0.50–0.65 | −1.01% | +1.13% | −2.13 пп |
| 0.65–0.80 | +11.81% | +1.98% | +9.83 пп |
| 0.80–0.90 | −6.16% | −0.18% | −5.98 пп |
| 0.90–0.98 | −0.94% | −0.23% | −0.71 пп |
| | | **итого** | **+1.29 пп** |

Полоса 0.65–0.80 выглядела находкой (n=396, интервал +6.27…+17.34), но
289 из 358 сделок там — киберспорт до его отключения. На свежей половине
там 38 наблюдений и −2.8 пп.

### Предсказать информированную сделку в момент её совершения — нельзя

Собрано 14 742 сделки с признаками момента сделки: удар по цене
относительно медианы за 30 минут, размер к потоку, активность и число
участников рынка, разброс цен, история кошелька. Логистическая регрессия,
разделение по времени.

**Метку модель предсказывает хорошо, денег не даёт.** AUC 0.728 вне
выборки, доля информированных в верхнем дециле 34.4% против базовых
14.9% — а ROI −2.4%. Причина видна, если печатать рядом долю разворотов:

| группа | «пошёл следом» | «пошёл против» | отношение |
|---|---:|---:|---:|
| все | 14.9% | 8.2% | 1.82 |
| верхние 5% по модели | 35.7% | 19.0% | 1.88 |
| нижние 30% | 3.8% | 3.4% | 1.12 |

Отношение не сдвигается: **признаки предсказывают движение, а не
направление.**

Репутация кошелька («ходил ли рынок за ним раньше») отношение сдвигала —
на обучающей половине. Вне выборки развалилась: +16.5% [+9.7; +23.3]
против **−59.4%** [−77.0; −41.9].

### Короткое окно наблюдения не помогает

Последняя проверка. Если перевес умирает между 20-й и 30-й минутой,
может, смотреть пять минут вместо двадцати? Пересчёт метки на 5 379
сделках, перевес по цене **на конце окна** — по той, что видна в момент
сигнала:

| окно | меток | по его цене | по VWAP окна | по цене на конце |
|---|---:|---:|---:|---:|
| 5 мин | 59 | +55.5% | +23.4% | **+11.4%** [+1.5; +21.2] |
| 10 мин | 173 | +54.1% | +23.4% | **+7.5%** [+0.7; +14.3] |
| 20 мин | 313 | +55.3% | +23.1% | +3.1% [−1.3; +7.5] |
| 30 мин | 440 | +55.6% | +22.6% | +1.4% [−2.3; +5.1] |

Узор ровно ожидаемый. Но проверка по времени его не подтверждает —
окно 10 минут: старая половина +15.2% [+4.0; +26.4], **свежая +2.1%**
[−6.3; +10.5].

И независимо от статистики: чтобы узнать, что последователи заплатили
больше за пять минут, нужны их сделки, а Data API отдаёт их пачками раз в
пять минут. Метка пятиминутного окна физически не существует раньше
10–15-й минуты.

### Рынок сам по себе не ошибается

Отдельный замер, не зависящий от чьих-либо сделок: 9 896 снимков цены
рынков, взятых из списка подряд. 1 215 рынков с живым стаканом и исходом,
один рынок — одно наблюдение:

| оценка рынка | рынков | винрейт | перевес | z |
|---|---:|---:|---:|---:|
| **все** | **1 215** | 14.5% при 15.2% | **−0.7 пп** | **−1.0** |
| < 0.05 | 792 | 0.5% при 1.2% | −0.7 пп | −1.8 |
| 0.05–0.20 | 141 | 7.8% при 10.1% | −2.3 пп | −0.9 |
| 0.20–0.40 | 89 | 32.6% при 29.6% | +3.0 пп | +0.6 |
| 0.40–0.60 | 84 | 44.0% при 49.2% | −5.1 пп | −0.9 |
| 0.60–0.80 | 34 | 61.8% при 69.0% | −7.2 пп | −0.9 |

Ни одной значимой полосы. Держится на обеих половинах по времени.

То есть **favourite-longshot bias, который видели СДЕЛКИ** (−6.7 пп на
цене 0.10–0.20, +3.9 пп на 0.60–0.70), **в безусловной выборке не
подтвердился** — это был отбор информированных покупателей, а не ошибка
рынка.

### Случайный рынок нельзя купить на $2000

| | переплата за размер, медиана |
|---|---:|
| случайный рынок | **30.8%** |
| рынок, где только что прошла крупная сделка | **0.6%** |

Арифметика: $2000 по цене 0.02 — это 100 000 долей, по 0.95 — 2 105.
Ордер $2000 с переплатой менее 5% проходит у 23% рынков; у 32% не
наливается вовсе. Торгуемость почти вся в дорогой половине шкалы: при
цене 0.20–0.60 торгуемы 7–8% рынков, при 0.95+ — 55%.

### Узких источников финансирования нет

Прогон по 1 022 кошелькам с исходами через Etherscan: источник распутан у
933, уникальных спонсоров **801**, и лишь два кошелька делят спонсора —
оба оказались платёжными шлюзами. Кластеров нет.

### Агент-оценщик (LLM) отложен

Пилот на Claude Opus и Sonnet: модели расходятся **между собой** (0.228)
сильнее, чем с рынком (0.135–0.191), обе завышают аутсайдеров в 10–20
раз. Реальная стоимость ~$0.20 за рынок — веб-поиск оплачивается
отдельно. Условия возвращения записаны в [docs/ROADMAP.md](docs/ROADMAP.md).

## Чему научил проект

Девять гипотез закрыто. Почти все — из-за ошибок измерения, которые
сначала показывали перевес.

1. **Перевес живёт в цене входа.** Любой подсчёт прибыли от цены
   трейдера — самообман. Пока достижимая цена не записана, мерить нечего.

2. **Порог в процентах не работает там, где величина ограничена.** Цены
   живут в (0,1], и порог «+25% к его цене» при цене 0.80 недостижим в
   принципе. Ветка погони молча не видела 30% рынков.

3. **Пропуск, связанный с измеряемой величиной, убивает замер.** У
   крайних рынков одна сторона стакана пуста, и середина не считалась
   ровно у тех рынков, ради которых замер затевался.

4. **Односторонний стакан — не цена.** Все семь «проигравших фаворитов по
   0.95+» имели ликвидность $1–4 и одну зависшую заявку. Вместе они
   давали z = −5.9; на рынках с живой книгой отклонения нет вовсе.

5. **Размер ордера — половина вопроса о доходности.** «Переплата 2%» и
   «переплата 30%» — это один и тот же рынок при разной сумме входа.

6. **Красивая полоса в разрезе — повод посмотреть её состав.** +9.83 пп в
   зоне 0.65–0.80 оказались старым киберспортом.

7. **Окно замера короче периода источника даёт чепуху.** Data API отдаёт
   сделки пачками раз в 5 минут — двухминутные замеры показывали то «7 ГБ
   в час», то «ноль сделок» на одном и том же трекере.

8. **Правила, продублированные в двух местах, расходятся.** Фильтр
   категорий так пропустил и киберспорт, и крипту.

9. **Тест с датой «в будущем» однажды ломается сам.** Дважды за месяц:
   сначала в `market_scanner`, потом — уже зная про грабли — в
   `price_sampler`.

10. **Оценка, которая падает с ростом выборки, — это ноль.** Ранние
    ончейн-сигналы: +9.4% на 78 сделках → +4.8% на 193 → +2.1% на 349 →
    −1.1% на 547. У настоящего эффекта оценка стоит на месте, а сужается
    интервал.

## Если возвращаться

Трекер автономен: надзиратель поднимает его после падения, чистка держит
историю 7 дней, бэкап делается перед каждым стартом.

```cmd
scripts\start_tracker.bat
```

Отчёты:

```cmd
python tools\paper_pnl.py --min-entry 0.50      # прибыль по нашей цене
python tools\calibration.py                     # калибровка рынка
python tools\stats.py                           # сигналы и исходы
python tools\shadow_report.py                   # что отбрасывают фильтры
```

Подробности — в [docs/](docs/):
[STATE.md](docs/STATE.md) · [ROADMAP.md](docs/ROADMAP.md) ·
[SETUP.md](docs/SETUP.md) · [PERFORMANCE.md](docs/PERFORMANCE.md) ·
[reports/](docs/reports/)

Единственное направление, которое осталось непроверенным, —
**маркетмейкинг**: Polymarket платит за ликвидность ($12 110 в сутки на
539 рынках из 1 200 просмотренных), мейкер не платит комиссию. Медианная
доходность при пропорциональном делении — 4% годовых, верхняя четверть —
16%. Это другой проект: нужна инфраструктура выставления заявок, капитал
и управление позицией. Данных, чтобы оценить снос цены именно на рынках с
наградой, собрать не успели — пересеклось всего 7 рынков.

## Техническое

Python 3.13, SQLite (WAL), `aiohttp`. Без numpy и pandas — вся статистика
на стандартной библиотеке.

Источники данных: Polymarket Data API (сделки), Gamma API (рынки и теги),
CLOB API (стаканы), Polygon RPC через websocket (ранние сигналы),
Etherscan v2 (источники финансирования).

Установка — [docs/SETUP.md](docs/SETUP.md). Секреты в `.env`, в
репозиторий не попадают.
